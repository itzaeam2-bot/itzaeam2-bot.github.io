# FocusBloom – Focus Timer Website

**COMP 3583 Human-Computer Interaction Project**

## What is FocusBloom?
FocusBloom is a clean, simple, and user-friendly focus timer web application designed to help users improve concentration using the Pomodoro technique.

### Features
- Focus mode (25 minutes)
- Short Break (5 minutes)
- Long Break (15 minutes)
- Visual progress ring
- Session counter and total focus time tracking
- Local storage (data saved in browser)
- Responsive design (works on phone and desktop)
- Clean modern interface following usability and UX goals

## How to Run
1. Open `index.html` in any modern browser (Chrome, Firefox, Edge, Safari)
2. Or host it on Netlify / GitHub Pages / any static hosting

No installation or build step required.

## Design Principles Applied (HCI)
- **Usability Goals**: Effective, Efficient, Easy to learn, Easy to remember, Safe, Utility
- **UX Goals**: Satisfying, Enjoyable, Aesthetically pleasing
- Clear visual feedback (progress ring + button states)
- Minimal cognitive load
- Consistent layout and colour scheme
- Mobile-friendly design
